# 三项目架构对比速查表

> 生成时间：2026-07-21
> 对比对象：**ClerkBox**（`d:\ClerkBox - 副本`，v1.6.0）、**OpenCode**（`d:\opencode`，v1.18.4）、**Claude Code**（`d:\claude-code-source`，v2.1.88）

## 1. 一句话定位

| 项目 | 定位 | 形态 |
|---|---|---|
| ClerkBox | Electron + React 桌面 AI 助手 | 单进程桌面应用 |
| OpenCode | Effect-native AI Coding Agent 平台 | Monorepo：CLI + TUI + Web + Desktop + Server |
| Claude Code | CLI-first 终端原生 AI 开发平台 | CLI + Ink + 可被 claude.ai 远程驱动 |

## 2. 技术栈对比

| 维度 | ClerkBox | OpenCode | Claude Code |
|---|---|---|---|
| Runtime | Node.js (Electron 42) | Bun 1.3 | Node.js |
| 语言 | TS 6.0 | TS 5.8 + tsgo | TS（编译产物） |
| 包管理 | npm | Bun workspace + catalog | npm（产品分发） |
| 构建 | Vite + electron-builder | Vite + electron-vite + SST + Nix | bun:bundle |
| 状态管理 | Zustand 5 + persist | Effect Service + SolidJS signals | 自研 Store + useSyncExternalStore |
| UI 框架 | React 19 + Tailwind 3 | SolidJS 1.9（Web/TUI 共用） | React + 自研 Ink |
| 样式系统 | Tailwind + MD3 CSS 变量 | Tailwind 4 + Kobalte + corvu | 自研 ANSI 渲染 |
| 数据库 | JSON 文件（sql.js 闲置） | SQLite + Drizzle (WAL) | 文件系统 + JSON |
| LLM 协议 | OpenAI-compatible fetch | Effect Route/Protocol/Transport + @ai-sdk/* | Anthropic SDK + Bedrock/Vertex/Foundry |
| Provider 数 | 1（OpenAI 兼容） | 30+ 插件式 | 1（Claude 多通道） |
| 异步模型 | Promise + AbortController | Effect Stream + Fiber | async generator + AbortController |
| 测试 | 无 | Bun test + happydom | VCR fixtures |
| 进程模型 | 主进程 + 渲染进程 | 单进程 + 可起 sidecar server | 单进程 + Bridge 派生子进程 |

## 4. 工具系统对比

## 12. 关键架构差距

ClerkBox 相比另两者的核心差距（按重要性排序）：

1. **无 MCP 支持** → 生态封闭，无法接入 Claude Desktop / Cursor 等工具生态
2. **无 Plugin 系统** → 无法第三方扩展，所有功能必须改主代码
3. **单一 Provider** → 只能 OpenAI 兼容，无法用 Anthropic 原生 / Google / Bedrock
4. **无事件系统/CQRS** → 流式中断后无法恢复，多窗口/多端不可能
5. **1500 行 main.ts 单体** → 无 services 分层，难维护
6. **JSON 文件 DB** → sql.js 闲置，会话多了启动慢
7. **无 git 工具** → 必须走 execute_command，无 diff/commit/status 原语
8. **无 LSP 集成** → 无诊断反馈，编辑无类型感知
9. **无快照/revert** → 仅 .clerkbox-bak 备份，无法选择性撤销
10. **无命令面板/快捷键** → UX 远不如 Claude Code 的 slash + Vim
11. **无多模态** → 仅文本，无图片/语音/文件
12. **无远程控制** → 手机/网页不能驱动桌面 AI
13. **无遥测/可观察性** → 线上问题难诊断
14. **无测试** → 重构风险高
15. **无跨平台打包** → 仅 Windows NSIS
