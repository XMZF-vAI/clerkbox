### 技能商店换源修复（国内网络兼容）
- **根因**：`raw.githubusercontent.com` 在国内被墙，导致所有 SKILL.md 下载超时 → 安装永远卡死。SkillHub API（skillhub.proclaw.cc）也不稳定。
- **搜索源双链路**：
  - 主源：SkillHub API（10 秒超时）
  - 回退：GitHub Search API（`api.github.com/search/repositories`，按 stars 排序）
  - 主源无结果或超时时自动切回退
- **SKILL.md 下载源双链路**：
  - 主源：jsDelivr CDN（`cdn.jsdelivr.net/gh/owner/repo/SKILL.md`，国内可达，自动解析默认分支）
  - 回退：raw.githubusercontent.com（jsDelivr 未缓存时兜底）
  - 每个请求 12 秒超时
- **前端错误提示**：`handleInstall` 失败时在卡片/详情页显示红色错误信息，5 秒后自动消失，不再静默失败。

### 技能安装第三次修复（并行请求 + 三源兜底）
- **根因**：之前的方案是串行逐个尝试 CDN URL（6 jsDelivr → 12 raw.github），最坏情况 18×12s = 216 秒，实际 8 秒超时也要等很久，且 jsDelivr/raw.github 在国内都不稳定。
- **主进程并行化**：`fetchSkillMdFromRepo` 改为 **3 个 CDN 源 × 6 路径 = 18 个 URL 全部并行发起**（`Promise.all`），第一个成功即返回，8 秒超时。三个源：
  1. jsDelivr CDN（`cdn.jsdelivr.net/gh/owner/repo/path`，自动解析默认分支）
  2. GitHub Raw（`raw.githubusercontent.com`，main/master 两个分支）
  3. GitHub API Contents（`api.github.com/repos/owner/repo/contents/path`，Accept: v3.raw，比 Raw 稳定）
- **前端 webFetch 兜底**：`installOnlineSkill` 如果 IPC 全部失败，还会用 `ipc.webFetch` 在渲染进程侧再试 jsDelivr + GitHub API，双保险。
- **日志**：主进程 hit 时 `console.log` 输出命中的 URL，方便排查。
