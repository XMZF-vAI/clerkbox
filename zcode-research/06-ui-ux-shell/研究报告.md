# 研究报告 06：整体 UI/UX 壳层（对话界面之外）

> 对标对象：ZCode v3.17.1 `packages/ui/src/{root,app-shell,settings,project-sidebar,plugin-ui}`、`packages/desktop/src/main/`、`packages/ui/src/styles.css`、`D:\ZCode\DESIGN.md`
> 调研日期：2026-11-01 · 用途：CB 产品级功能与 UI 全面对齐参考

---

## 0. TL;DR

壳层五个最值得整抄的决策：①设置页=tab+声明式分区注册表+Scope 三级（用户/项目/远程）；②插件市场为侧栏一级视图+「试用」mention 注入草稿的转化闭环；③新任务=草稿会话（header 全域 drop、推荐词可导航）；④样式单 `@theme`：角色字号由 `--ui-font-size` 一个变量派生+语义色全 color-mix；⑤DESIGN.md 作为 agent 可执行的硬约束文档。

**重要纠偏**：ZCode 的 work/code 模式（office/coding）**没有**独立首页/独立工具集的壳层分叉——它只是轻量偏好（影响设置页取值、推荐提示词、遥测），真正的分叉是 workspacePurpose（project=绑目录 vs conversation=纯聊天）。CB 已实现的界面模式切换方向与此一致，不必加重。

---

## 1. 应用壳层

- 层级：`Root.tsx` → `root/RootShell.tsx`（h-dvh 根+全局宿主：AlertDialog/Confirm/PluginUi）→ `root/RootWorkspaceContent.tsx`（每工作区一个 App）→ `App.tsx`（工作区级总编排，eslint max-lines 自注释）→ `app-shell/WorkspaceShellLayout.tsx`。
- **多 workspace = 窗口内 tab**（`store/tabStore.ts`）：`WorkspaceTabState | SettingsTabState`——**设置页也是一个 tab 不是独立窗口**；支持崩溃后 restore。
- 布局：左侧 `WorkspaceSidebar`（**项目树是唯一组织视图**：项目→任务两级）+ 顶部 `WorkspaceHeader`（h-12、`[app-region:drag]`、draft/task 两 variant）+ 主区对话 + 底部终端面板 + 右侧多 tab 侧栏（终端/浏览器/Git/workflow run/子代理会话，状态在 `lib/workspaceSidePane.ts`，react-resizable-panels，面板独立 frame+4px 间隙）。
- 主视图路由只有三值：`"chat" | "automations" | "plugin-store"`——**路由由 Shell 唯一持有**，导航按钮只展示选中态。
- 全局命令：`command-center/CommandCenterDialog.tsx`（命令面板）+ 快捷键内核 `shortcuts/bindings.ts`（纯函数匹配/录制/冲突检测+IME 噪声过滤）。
- 侧栏 footer：头像/套餐徽章/用量汇总/界面模式切换/语言/设置。

## 2. work/code 界面模式（纠偏）

- `lib/interfaceMode.ts`：`"office" | "coding"`；localStorage `zcode-interface-mode`；**`normalizeInterfaceMode` 把旧值静默映射**（存量用户升级不丢选择）。
- 三个入口：引导第二步 radio 卡 / 侧栏 footer 菜单 / 设置页 General Select。
- 实际差异：设置页取值、**首页推荐提示词**（`v4/officeSuggestedPrompts.ts`：development/office/finance/utility 四类，cn/en 双语、可绑插件图标）、遥测。**没有独立工具集。**
- 真正的工作区性质分叉是 `workspacePurpose.ts`：`"project"（绑目录）| "conversation"（无文件夹聊天）`。

> CB 对照：CB 的界面模式切换（ff8682a）+ work 首页技能切换器（c9e0ad6）已走在同一方向。可抄：**normalize 函数护旧值**、推荐词四分类+可导航动作。

## 3. 首页 / 新建任务 UX

- 新建入口：侧栏顶部一行按钮（图标+快捷键标签），埋点 featureId。
- **草稿模型**：`CreateTaskOptions{draftId, ..., prefill, createSource}`——「只写草稿，不自动发送」；未归类草稿放 HomeOnly 区域。
- **首页 = draft variant 的 WorkspaceHeader，整个 header 是文件 drop 区**——drop 只路由到既有 composer 上传（不建第二个状态机），激活时盖 accent/55+backdrop-blur 遮罩。
- 空草稿推荐：服务端下发+本地化、可绑定插件 stableId、**可带 `NAVIGATE:AUTOMATIONS` 跳转动作**；轮换逻辑独立文件。
- 引导触发：按本地记录判定，**失败保守判 false**（不打扰老用户），3 秒放行预算。

## 4. 设置体系

- 分区=**声明式注册表**（`settings/settingsPageConfig.ts`）三组：basics（general/appearance/modelProvider/browser/shortcuts...）、agentCapabilities（personalization/memory/subagents/plugins/mcp/skills/commands/automations/hooks）、dataAndStats（dataSync/usage/projects/archives）；平台门禁走工厂函数。
- **Scope 体系**：`"user"`=本机 / `source-user:<id>`=远程设备 / 其余=项目 key；Scope 菜单按设备分组含在线状态；**选中的远端设备离线时该页读写直接报错，不回退本机**。
- 视觉框架：统一内容列 max-w-4xl、`SettingsRow`（label+192px 控件栏 grid）、`SettingsGroupCard`；每个 section 独立文件；搜索框+面包屑；设置项↔命令中心互相深链。

## 5. 插件市场 / 技能管理

- **插件市场是侧栏一级主视图**（MainView="plugin-store"）：列表/详情/第三方市场源/卸载确认；官方市场自动刷新（claim 机制）；
- **「试用」闭环**：`buildPluginStoreTryMention` 直接把插件 mention 注入 composer 新草稿——市场到对话一步；
- 已安装管理：详情行/警告列表/**作用域三级菜单（用户/项目/远程）**/配置项/能力投影；
- 技能：搜索/过滤/逐技能 Switch/按插件分组/从他方 agent 导入/mention 试用/诊断码。

> CB 对照：CB 有 list_skills 只读工具+输入框技能选择器。可抄：技能管理进设置页（开关+诊断）、「试用」mention 注入。

## 6. 会话管理 UX

- 项目树下任务行：未读信号/置顶/远程连接状态图标；
- **分组视图**（TaskGroupedView）：dnd-kit 拖任务入组/组颜色/sticky 组头/顶层虚拟化/折叠态持久化/闲时专属组；
- **搜索三层**：全局任务快搜（结果上限 9）/会话内查找（findIndex+DOM 高亮+`--color-find-highlight` token）/归档过滤（**按 hostId+project 分组，筛选态不随搜索消失**）；
- 分享：生成链接+**权限选择器**+只读时间线；Markdown 导出；打印 PDF。

## 7. 视觉体系

- DESIGN.md 硬约束：`text-ui-*` 强制档位（详见报告 01 §10）；「calm, dense, operational」；品牌色永不做整页背景；海拔 4 档；动效 low-drama 禁 springy；断点角色表（sm 对话框/md 网格/lg 桌面工具栏/xl 聊天/2xl 阅读帽）；4.5:1 对比硬指标。
- `styles.css`（2421 行）`@theme`：`--text-ui-*` 全由 `--ui-font-size` 派生（±Npx）；专用色板（终端 ANSI/用量图表 6 色/热力图 5 阶/git 7 态/mention node 5 族）；主题三层（.dark + Zai Light + Zai Dark）；`normalizeThemePreference` 把 light/dark 归一为 zai-*。
- **CJK mono 字体栈**：Consolas 无中文字形 → 显式补雅黑/苹方（CB 的中文代码块同样适用）。

## 8. i18n

- `packages/ui/src/i18n/`：**自制轻量 intl**（id 查表+`{key}` 占位符，无 ICU 复数）；仅 zh-CN/en-US 两个单文件大对象（扁平命名空间）；
- 偏好：localStorage + 设置服务双源统一裁决；**broadcast channel `"state:locale"` 跨窗口同步**；切换器单按钮循环（中/En）。

> CB 对照：CB 的 src/i18n/locales/{en,zh-CN}.ts 结构一致。可抄：跨窗口广播同步。

## 9. 桌面集成（packages/desktop/src/main）

- 托盘（win32+linux）：16px 逻辑尺寸、1x/2x 双份合成防糊、未读红点独立合成（任务栏/托盘分离）；
- 通知：**3 秒去重窗口，键=status+requestId（审批请求按 requestId 而非 taskId）**；上限 100 LRU；**任一窗口聚焦则抑制**；
- 自动更新：electron-updater+自研 manifest provider；后台 15min/可见态 2min 轮询；升级后 release notes 流；Windows Authenticode 校验；强更 guard；
- 协议唤起：`zcode:` deep link + OAuth 回调 + 二实例转发（single-instance 收口）；
- 窗口：默认 1200x800，**最小 480x640**；bounds/maximized 分开持久化 250ms 防抖；自绘窗 chrome；**命令 ID 枚举在 shared 供托盘/菜单/渲染层三方复用**；
- 其他：Cron 定时调度、Chrome Cookie 导入族、CUA 权限面板、手机远控、插件 iframe 沙箱（main+preload 双侧）。

## 10. 响应式与小窗

- **named Container Query**（Tailwind v4 `@container`，10 处）：让子组件响应**面板宽度**而非窗口宽度——侧栏/侧板拖宽时内部密度自适应；`@max-[360px]/conversation:` 窄流隐藏装饰；
- 小窗/移动：`(max-width: 767px)` 切换单列+抽屉移动壳；根节点 `h-dvh` 防移动地址栏裁切；
- 侧栏：toggle 命令+持续宽度记忆；header padding 过渡只对 padding 属性（防滚动条颜色非合成动画）。

## 11. CB 对齐建议

**P0（低成本高感知）**：
1. DESIGN.md 化：把 CB 的视觉约束写成一份硬约束文档（字号档位/语义色纪律/海拔/动效），给后续开发与 agent 用；
2. `--ui-font-size` 单变量字号缩放 + 字号档位审计（CB 现在的 text-sm/base 混用收敛到档位）；
3. 通知去重按 requestId + 窗口聚焦抑制（CB 的 IM 机器人/审批通知直接受益）；
4. CJK mono 字体栈修复。

**P1**：
5. 设置页声明式分区注册表+设置页进 tab 体系；
6. 技能管理 UI（设置页：开关+诊断+按来源分组）+「试用」mention 注入；
7. 新任务草稿模型（先落草稿再定项目 + header 全域 drop）；
8. named Container Query 替代 JS 宽度侦测。

**P2**：命令面板+快捷键录制内核、会话分组看板、分享只读时间线、多 tab 侧栏注册表、i18n 跨窗口广播。
